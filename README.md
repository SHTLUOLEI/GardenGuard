# 90 秒守点（Defense90）

Unity 测试题实作：竖屏守点小游戏，目标平台抖音小游戏（Unity WebGL），Unity 2022.3.62f3c1。

- 项目说明（运行、结构、TA、优化记录、已知问题、用时）：[GameUnity/README.md](GameUnity/README.md)
- 性能问题定位与优化（第 3 题）：[GameUnity/PERFORMANCE.md](GameUnity/PERFORMANCE.md)
- 笔试题答案：[GameUnity/笔试答案.md](GameUnity/笔试答案.md)

## 目录

```
GameUnity/    Unity 工程，用 Unity Hub 打开这个目录
GameConfig/   Luban 配置表源文件（xlsx）和导表脚本
Tools/        框架自带的构建与导表工具
```

工程基于开源框架 DGame（MIT 协议），框架原说明见 [DGame框架说明.md](DGame框架说明.md)。
